## 🚀 Quick Start

```bash
# 1. Setup (1 minute)
cd packages/nextjs
yarn install

# 2. Configure (1 minute)
echo "NEXT_PUBLIC_AEGIS_ADDRESS=0x..." > .env.local

# 3. Run (1 minute)
yarn dev

# 4. Access (instant)
http://localhost:3000/aegis
```

**Total Time to Launch**: ~5 minutes ⚡
